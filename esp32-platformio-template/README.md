# ESP32 PlatformIO Template

Generisches, bewusst leeres ESP32-Startprojekt für PlatformIO mit Arduino-Framework.

## Projektstruktur

```text
esp32-platformio-template/
├── src/
│   └── main.cpp
└── platformio.ini
```

## Inhalt

- `src/main.cpp` enthält nur ein minimales `setup()` und `loop()`
- `platformio.ini` enthält nur die grundlegende ESP32-/Arduino-Konfiguration

## Start

1. Projekt kopieren oder umbenennen.
2. Board oder weitere PlatformIO-Optionen in `platformio.ini` anpassen.
3. Eigene Logik in `src/main.cpp` ergänzen.
